# v1.1.0 stable baseline

Stable source version: v1.1.0. The [GitHub release page](https://github.com/RahulSinghParmar/Portfolio/releases/tag/v1.1.0) records the published tag and source commit. A source release does not imply a production website deployment.

This baseline preserves the responsive portfolio accepted by Rahul after multi-device testing. It includes the transparent portrait, responsive hero topology, bounded signal animation, interactive capability map, mobile case-study disclosures, current AWS identity, Cloudflare delivery and repository previews.

Version identifiers in the package, footer, Worker defaults, environment examples and Wrangler bindings agree on v1.1.0. The historical v1.0.0 changelog and Docker rollback documentation remain historical records.

## Local preservation

After `npm run release:check`, run `pwsh -File scripts/prepare-source-snapshot.ps1`. The script archives existing Git-tracked and non-ignored source files, excluding experiments and generated output. The archive is accompanied by a SHA-256 checksum. It does not include local secrets or source photographs.

The isolated visual experiment under `experiments/` is not part of this baseline or its Cloudflare asset directory. The stable website continues to build from `app/`.

## Publication procedure

1. Review the stable source diff and local validation results.
2. Commit under the configured RahulSinghParmar identity.
3. Push the reviewed candidate and pass GitHub Release quality.
4. Publish the v1.1.0 tag/release against the accepted, CI-validated stable commit.
5. Before website promotion, deploy the exact commit to the protected preview workflow and verify it.
6. Promote production only through the separately approved cutover procedure. Publishing GitHub source does not authorize Cloudflare deployment.

## Validation

The local release gate passed: formatting, lint, TypeScript, 16 Worker tests, static export, performance budgets, SEO contracts and Cloudflare packaging dry run. All 73 local deployment checks passed. Rahul accepted the stable layout after multi-device review. Hosted GitHub CI must pass again against the released source.
